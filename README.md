# Sabores de la GLA

App web de gestión de viandas, pedidos, stock y producción (mobile-first).

**Stack**: Node.js + Express · Supabase · HTML/CSS/JS vanilla

**Deploy**: https://viandas-gla.onrender.com (Render free plan)

## Setup

```bash
cp .env.example .env  # completar SUPABASE_URL y SUPABASE_SERVICE_ROLE_KEY
npm install
npm run dev
```

Ver `AGENTS.md` para documentación completa del proyecto.
